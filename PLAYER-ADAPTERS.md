# Player installation

[Download the installer](https://github.com/ardenee/Archive_Stream_Player/releases/tag/v0.1.7), run it and select your installed music players. Portable installations can be chosen manually.

| Player | Installation |
| --- | --- |
| Winamp / WACUP 32-bit | Installs the native input and playlist plugins |
| foobar2000 32/64-bit | Installs the matching native component |
| AIMP 32/64-bit | Installs the matching native plugin |
| XMPlay 32-bit | Installs `xmp-archive-stream.dll`. In **Options → Decoders**, select the **Archive Stream Player** tree page, or use **Archive Stream ZIP/7z/RAR → Config** for the standalone dialog. XMPlay handles ordinary ZIP files itself |
| VLC 3 64-bit | Installs `libarchive_stream_plugin.dll` into VLC's native `plugins\access` directory and updates its plugin cache. Open ZIP, 7z or RAR normally via **Media → Open File** (select All Files if needed), or drag an archive into VLC. No launcher or HTTP bridge required |
| MusicBee 32-bit | Native BASS decoder and MusicBee Tools plugin; archive-only playlist discovered by SDK name/path, not a numeric tab ID. ID3 V5 aliases provide embedded tags and exact .ast manifest; after low-priority PCM verification, directly streamable MP3s with a genuine Info/Xing frame publish one bounded real frame so MusicBee can populate native Time (DEV Broken Silence 9/9, 37:00 total). Failed/missing headers, nonstreamable archives and non-MP3 codecs retain safe metadata-only aliases. The separate skinned Verified Durations window remains optional and never overlays native tabs; ordinary MP3s remain MusicBee-owned. |

Plugin settings follow the player's own UI: **Winamp/WACUP** uses its input plugin's compact configuration dialog; **foobar2000** uses Preferences → Tools → Archive Stream; **AIMP** uses Preferences → Plugins → Archive Stream Player with AIMP SDK-native tabs and controls; **XMPlay** uses Options → Decoders → Archive Stream Player (Config remains available); and **VLC 3 x64** uses Tools → Preferences → Show settings: All → Input / Codecs → Access modules → Archive Stream Player. VLC defaults to shared settings unless its VLC-specific override checkbox is enabled. Other adapters continue using consistent shared settings underneath, although playlist title rendering varies by host.

**VLC native Open File integration (November 19, 2026):** VLC 3 x64 now registers two SDK access handlers in its DLL: a narrowly scoped local `file` handler redirects only recognised archives to `ast://`, which generates the album playlist and streams audio through the shared backend. Native VLC 3.0.24 DEV playback verified nine-track ZIP, single-track 7z and RAR; ordinary MP3 remained on VLC's built-in filesystem module. A host-CRT allocation mismatch discovered during testing was fixed before release. The user-facing VLC integration no longer requires PowerShell. VLC 1.5.1 exposes its own preferences under **Tools → Preferences → All → Input/Codecs → Access modules → Archive Stream Player**, defaulting to the shared adapter settings until VLC-specific overrides are explicitly enabled. The album now opens through VLC's native `pf_readdir` directory interface, directly filling title, artist, album, album artist, genre, year, track number and verified MP3/FLAC/WAV duration fields on the playlist items before playback. DEV Subspecies 4 passed 9/9 pre-play tags and durations; generated 7z/RAR and ordinary MP3 routing also passed. Solid/encrypted and unsupported headers remain unknown until VLC decodes individual tracks. To confirm our plugin is active, open VLC **Tools → Messages**, set verbosity to 1 or 2, reopen an archive, and look for `Archive Stream Player: native tagged archive directory opened` messages. VLC 4/32-bit remain unsupported.

**AIMP direct-stream audio properties (November 19, 2026):** The native adapter now supplies AIMP's writable Duration (seconds), Bitrate, SampleRate and Channels from genuine, bounded MP3 Info/Xing, FLAC STREAMINFO and WAV RIFF metadata. AIMP's FileInfo duration is in seconds. A prior incorrect switch to milliseconds made the playlist values 1,000 times too large despite successful SDK writes. The native adapter now passes seconds and checks real playlist metadata. This is independent of Use File Tags and never pre-extracts/decodes full audio for playlist display. For MP3, a bounded 4 MiB ID3 skip supports embedded artwork before the first audio frame. When a genuine LAME encoder extension is present, the initial MPEG duration subtracts its recorded encoder delay and end padding. Real DEV comparison for Neptune: untrimmed 512.522449 s, AIMP decoder 512.481247 s; the corrected 512.481247 s matches exactly. The short difference can otherwise cross a one-second display rounding boundary, independently of the earlier seconds/milliseconds API mismatch. DEV Subspecies 4 test: all nine tracks identified, **74:04** total, **44.1 kHz, 320 kbps, stereo**, and AIMP accepted all values. Other formats or missing trusted headers are not yet covered.

**AIMP title refresh and decorations (November 19, 2026):** Native AIMP adapter registers an archive-URI file-info extension and uses one-shot host-thread IAIMPPlaylistItem::ReloadInfo scoped strictly to Archive Stream tracks after expansion, restart, and Track titles settings save. An actual AIMP 5.40 x86 run loaded correct embedded metadata for 9/9 Subspecies 4 MP3s (e.g. Cosmic Bazaar — Neptune and Tetriz — Keep The Change), and the host repainted the affected title column. AIMP Track titles has shared Title prefix and Title postfix fields (20 UTF-8 bytes each); these wrap only preset titles. Use File Tags overrides all title formatting and displays the embedded title. Same shared registry fields are available to the standalone settings UI and compatible foobar preferences.

The **Configure Archive Stream Player** shortcut manages shared passwords, cache, titles, **Use File Tags** (off by default; overrides title presets), and logging. MusicBee uses ID3 aliases; AIMP/VLC can use a bounded direct-stream tag probe; foobar2000/XMPlay use native host metadata decoding.

WACUP 64-bit and Windows Media Player are not included as native installer options.
